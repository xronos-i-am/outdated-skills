# outdated-skills

Хук старта сессии: сообщает агенту об отставших зависимостях apm.yml проекта

## Установка

```bash
make install
```

## Разработка

Обвязка разработки приходит из приватного пакета [skill-kit](https://github.com/xronos-i-am/skill-kit): без доступа к нему `make setup` не пройдёт, а `make install` пройдёт.

| Команда | Когда |
| --- | --- |
| `make setup` | после клона, после правки скилла и чтобы взять свежий skill-kit. Если он обновился, поднимает его версию в `apm.yml` — закоммитьте |
| `make release [minor\|major]` | выпустить версию скилла: тег `vX.Y.Z` и push |

Раскладка каталогов:

- исходник скилла, его скриптов и ассетов — `.apm/skills/<скилл>/`, правка идёт туда;
- `.claude/`, `.agents/` и `.opencode/` собирает `make setup` из `.apm/`, правки в них затираются следующим `make setup`;
- `apm_modules/` — зависимости пакета, а не код этого репозитория.
